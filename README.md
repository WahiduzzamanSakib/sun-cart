

# 🌞 SunCart – Summer Essentials Store

SunCart is a modern summer eCommerce web application where users can explore and purchase seasonal essentials like sunglasses, summer outfits, skincare products, and beach accessories. The platform provides a smooth shopping experience with authentication, protected routes, and a fully responsive UI.

---

## 🚀 Live Demo

👉 [https://sun-cart-plum.vercel.app](https://sun-cart-plum.vercel.app)

---



## 🎯 Project Purpose

The goal of **SunCart** is to build a modern and responsive eCommerce platform focused on summer products. Users can browse products, view details, authenticate securely, and manage their profile.

---

## 🎯 Project Deploy

* Vercel

## ✨ Key Features

* 🌐 Fully responsive design (Mobile, Tablet, Desktop)
* 🛍️ Product listing from static JSON data
* 🔥 Featured "Popular Products" section
* 📄 Product details page (protected route)
* 🔐 Authentication using BetterAuth
* 🔑 Email/password login + Google login
* 👤 User profile page
* ✏️ Update profile feature 
* 🎨 Modern UI with Tailwind CSS + HeroUI
* ⚡ Smooth navigation using Next.js App Router
* 🔑 Email/password login + Github login
