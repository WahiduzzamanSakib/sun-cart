
# 🌞 SunCart – Summer Essentials Store

SunCart is a modern summer eCommerce web application where users can explore seasonal essentials like sunglasses, summer outfits, skincare products, and beach accessories. The platform provides a smooth shopping experience with authentication, protected routes, and a fully responsive UI.

## 🎯 Project Purpose

The goal of **SunCart** is to build a modern and responsive eCommerce platform focused on summer products. Users can browse products, view details, authenticate securely, and manage their profile.

---

## ✨ Key Features

- 🌐 Fully responsive design (Mobile, Tablet, Desktop)
- 🛍️ Product listing from static JSON data
- 🔥 Featured "Popular Products" section
- 📄 Product details page with protected routes
- 🔐 Secure authentication using BetterAuth
- 🔑 Email/Password login
- 🔑 Google Login
- 👤 User profile page with update functionality
- 🎨 Modern UI with Tailwind CSS + HeroUI
- ⚡ Fast and smooth navigation using Next.js App Router

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/WahiduzzamanSakib/sun-cart.git
```

### 2. Go to Project Directory

```bash
cd sun-cart
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:3000
```

---

## 🔐 Environment Variables

Create a `.env.local` file in the root directory and add the required environment variables.

```env
MONGODB_URI=your_mongodb_connection_string
BETTER_AUTH_SECRET=your_secret_key
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
```
